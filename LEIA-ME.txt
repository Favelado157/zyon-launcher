TEMPLATE ZYON PARA DISCORD — WINDOWS

O QUE TEM
5 categorias, 20 canais e 8 cargos.
Informações, Comunidade, Suporte, Salas de voz e Equipe privada.
Inclui os 8 emojis Zyon em PNG e textos iniciais para os canais.
Confira ESTRUTURA.md para revisar o modelo completo.

COMO USAR SÓ O MODELO
Você pode criar manualmente os canais e cargos seguindo ESTRUTURA.md.
Os textos prontos estão em TEXTOS-PARA-COPIAR.md.
Os PNGs estão em emojis: Configurações do servidor > Emojis > Enviar emoji.

COMO APLICAR AUTOMATICAMENTE
1. Extraia o ZIP inteiro para uma pasta no seu PC.
2. Instale Python 3.12 para Windows, se necessário:
   https://www.python.org/downloads/windows/
   Marque Add python.exe to PATH. O programa requer Python 3.11 ou mais recente.
3. Recomendamos criar um servidor novo e vazio chamado Zyon no Discord.
   O aplicador também funciona em um servidor existente, preservando os canais.
4. Crie um aplicativo de bot separado, por exemplo Zyon Setup:
   https://discord.com/developers/applications > New Application.
   Abra Bot e obtenha o token (Reset Token / Copy, conforme aparecer).
   Este programa usa um token de BOT. Não use o token da sua conta pessoal.
   Não precisa ativar intents privilegiados.
5. Ative Modo desenvolvedor em Configurações do usuário > Avançado no Discord.
   Clique com o botão direito no servidor > Copiar ID do servidor.
6. Abra APLICAR-TEMPLATE.bat. As dependências são instaladas automaticamente.
7. Cole o ID do servidor e o token DO BOT no terminal do seu próprio PC.
   O token não aparece enquanto você digita e não é salvo em arquivo.
8. Se o bot ainda não estiver no servidor, será mostrado um link de convite.
   Abra esse link, selecione o servidor correto e autorize as permissões.
   Depois execute APLICAR-TEMPLATE.bat novamente.
9. Confira o NOME e ID do servidor mostrados no terminal, o plano e ESTRUTURA.md.
   Digite CRIAR para aplicar, ou qualquer outra coisa para cancelar.
10. Aguarde. O bot cria a estrutura e publica os textos iniciais.
    O Discord pode limitar a velocidade de criação. Mantenha a janela aberta.

PERMISSÕES E CARGOS
O bot precisa gerenciar canais, cargos e o servidor, além das permissões
que serão dadas aos cargos Administrador e Moderador, como moderação de
membros e mensagens. O convite solicita as permissões necessárias, sem
solicitar a permissão Administrator.
Não é necessário colocar o bot acima do dono ou de toda a equipe existente.
Não remova as permissões do bot durante a aplicação.
Os cargos criados não são atribuídos automaticamente. Faça a atribuição
manualmente e revise as permissões antes de conceder cargos à equipe.
Fundador é um cargo de identificação: a propriedade do servidor continua
sendo definida pelo Discord. VIP e Membro são cargos de organização.
Não há atribuição automática de cargos nem bot de verificação.

LINK NATIVO DO TEMPLATE
Ao terminar, o programa tenta criar um modelo nativo do Discord.
O link aparece no terminal e em LINK-TEMPLATE-<ID>.txt.
Quem tiver esse link pode criar outro servidor baseado no modelo.
IMPORTANTE: o modelo nativo inclui nomes e permissões de TODOS os canais
e cargos desse servidor, inclusive os preexistentes e as áreas privadas.
Mensagens, membros, bots e emojis não são copiados pelo link nativo.
Para obter apenas a estrutura Zyon, use um servidor novo e vazio.
Se você já tinha canais padrão, eles também serão preservados e incluídos.
Se preferir, ajuste o servidor antes de gerar o modelo pelas configurações
no próprio Discord. Em outros servidores criados pelo link, envie os emojis
e use TEXTOS-PARA-COPIAR.md para publicar os textos.
O Discord permite até 5 modelos por servidor. Se não houver espaço, a
estrutura será aplicada e o programa explicará como liberar um modelo.

PRIVACIDADE DA EQUIPE
A categoria Equipe é criada com acesso para Fundador, Administrador,
Moderador, Suporte e Desenvolvedor, além do bot aplicador.
Dono do servidor e pessoas com Administrator continuam com acesso,
conforme as regras de permissões do Discord.
Os canais de ajuda e bugs são públicos: não publique tokens ou senhas.

RETOMAR OU EXECUTAR NOVAMENTE
O programa guarda os IDs do que criou em progresso-<ID>.json.
Mantenha esse arquivo para retomar uma instalação interrompida sem duplicar
canais, cargos ou mensagens iniciais. Os itens gerenciados já existentes
são preservados; o aplicador não força alterações nos ajustes feitos depois.
Se existir um cargo/categoria com nome igual e sem registro no progresso,
o programa para antes de aplicar para que você possa resolver o conflito.
Nenhum canal ou cargo existente é apagado. Não exclua o arquivo de progresso
para tentar reaplicar em um servidor já configurado.
Se mudar a estrutura depois, execute novamente para sincronizar seu modelo
nativo ou use a opção de sincronização nas configurações do Discord.

O QUE VOCÊ CONFIGURA DEPOIS
- Atribua os cargos à equipe e à comunidade.
- Envie os 8 emojis pelo menu Emojis.
- Adicione e configure bots de música, tickets ou automoderação, se desejar.
- Canal registro-manual recebe anotações da equipe; ele não grava logs sozinho.
- Boas-vindas contém um texto fixo; não envia uma mensagem por entrada de membro.

SEGURANÇA DO TOKEN
Nunca envie o token aqui, em mensagens, prints, GitHub ou nos canais do servidor.
O aplicador pede o token em memória e o descarta quando termina.
Os arquivos de progresso não contêm o token.
Após aplicar, você pode remover o bot Zyon Setup do servidor; os canais,
cargos e mensagens criados permanecem. Seus bots de uso diário são separados.

VERIFICAÇÕES
Testes com a API simulada: criação, permissões de equipe privada e leitura,
retomada após falha, reaplicação sem duplicatas, conflitos e geração/sincronização
do link de template. A conexão real depende do seu bot e das permissões no Discord.
